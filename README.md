# Landing page de portfólio

Projeto responsivo criado com HTML, CSS e JavaScript puro.

## Como usar
1. Extraia os arquivos para uma pasta do projeto.
2. Abra `index.html` no navegador ou use a extensão Live Server no VS Code.
3. Troque `Seu Nome`, links de GitHub/LinkedIn e e-mail pelos seus dados reais.
4. Atualize os links dos projetos para seus repositórios reais.
5. Coloque os PDFs dos certificados dentro da pasta `certificados`, usando estes nomes:
   - `html5-fundamentos.pdf`
   - `css3-estilizando.pdf`
   - `javascript-fundamentos.pdf`

Os links dos certificados só funcionarão depois que os arquivos PDF forem colocados na pasta correta.
